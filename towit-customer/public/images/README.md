# Estructura de Imágenes de Towit

Carpeta de organización de imágenes para la aplicación web de Towit.

## Estructura

```
public/images/
├── hero/          - Imágenes para la página principal y hero sections
│   └── towit-hero.jpg (usado en página de inicio)
└── rides/         - Imágenes relacionadas a viajes
    └── (aquí irán imágenes de prueba de viajes)
```

## Formatos recomendados

- **Formato**: JPG o PNG
- **Tamaño**: Optimizar a máximo 1-2MB
- **Resolución**: Mínimo 1920x1920 para imágenes cuadradas
